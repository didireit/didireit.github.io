PROJET 01 — CLOUD & DEVOPS

Déploiement automatisé de WordPress sur AWS

Conception et déploiement d'une infrastructure Cloud automatisée permettant d'héberger une application WordPress sur AWS.

AWS Docker Kubernetes Terraform GitLab CI/CD Helm ArgoCD Datadog

01 — CONTEXTE

Un projet orienté Cloud et automatisation

Ce projet a été réalisé en équipe de cinq personnes dans le cadre de ma formation DevOps & Cloud chez DataScientest.

L'objectif était de déployer une application WordPress sur une infrastructure AWS entièrement automatisée.

02 — OBJECTIF

Automatiser l'ensemble du cycle de déploiement

L'infrastructure devait couvrir les différentes étapes du cycle de vie de l'application, depuis la création des ressources Cloud jusqu'à la supervision en production.

03 — MON RÔLE

Infrastructure et automatisation

Infrastructure Cloud

Participation à la conception et au provisioning des ressources AWS avec Terraform dans une approche Infrastructure as Code.

Conteneurisation

Utilisation de Docker et Kubernetes pour déployer et orchestrer les composants de l'application.

CI/CD

Mise en place d'une pipeline GitLab CI/CD permettant d'automatiser les tests et les déploiements.

GitOps & supervision

Utilisation de Helm et ArgoCD pour gérer les déploiements sur plusieurs environnements, avec supervision grâce à Datadog.

04 — TECHNOLOGIES

Stack technique

AWS EC2 S3 VPC Docker Kubernetes Terraform GitLab CI/CD Helm ArgoCD Datadog

05 — RÉALISATIONS

De l'infrastructure à la supervision

L'infrastructure Cloud a été provisionnée avec Terraform, permettant de gérer les ressources AWS sous forme de code.

Les applications ont ensuite été conteneurisées avec Docker et orchestrées avec Kubernetes.

Une pipeline GitLab CI/CD a été mise en place afin d'automatiser les tests et les déploiements.

L'approche GitOps avec Helm et ArgoCD a permis de gérer trois environnements : développement, préproduction et production.

Enfin, Datadog a été utilisé pour assurer la supervision de l'application en production.

06 — RÉSULTAT

Une infrastructure automatisée de bout en bout

Le projet a abouti à une infrastructure Cloud entièrement automatisée et documentée, couvrant le cycle complet d'une application moderne, du provisioning jusqu'à la supervision.
